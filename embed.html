Discord Embed Generator

Make Discord show custom title/description text when you paste a link — without needing to send an actual message with that text.

How to use it

  1. Take the text you want Discord to show.
  2. URL-encode it (spaces, punctuation, etc. need to be escaped).
  3. Paste it after /embed/ on the worker URL below.
  4. Send that link in Discord — the unfurler will show your text as the embed title/description.

URL format

https://woopsite.woopetcool.workers.dev/embed/<your-encoded-text>

Example

Want the embed to say hello world!?

https://woopsite.woopetcool.workers.dev/embed/hello%20world%21
The embed itself is generated server-side by a Cloudflare Worker (not this page) — Discord's unfurler reads raw HTML meta tags and doesn't run JavaScript, so this page can't produce the effect on its own.

This site pings a Discord webhook on load and uses a third-party counter (countapi.mileshilliard.com) to detect traffic bursts.
